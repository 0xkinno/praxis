# PRAXIS Demonstration Script

This is the script for the 3-minute video demonstration of PRAXIS: Continuous Data Trust Intelligence for DataHub.

## Video Overview & Timing

| Timestamp | Visual Content | Audio / Narrative Guide |
|---|---|---|
| **0:00 - 0:10** | **Title Slide:** "PRAXIS: Continuous Data Trust Intelligence for DataHub." Dark, high-end editorial background animation (`hero-trust-network.png`). | "Welcome to PRAXIS, an autonomous trust intelligence agent for DataHub that continuously evaluates, propagates, and remediates data quality issues across your entire catalog." |
| **0:10 - 0:30** | **DataHub UI / Overview:** Show DataHub running with showcase-ecommerce data. Show datasets like `order_details` and `orders`. | "In a modern data catalog like DataHub, you have dozens of tables, dashboards, and models. But which ones can you actually trust for production analytics or machine learning training?" |
| **0:30 - 1:00** | **Triggering Assessment:** Switch to the PRAXIS dashboard and click **Trigger Live Assessment**. Show the live WebSocket status log printing: *Census inventorying*, *Calculating trust scores...* | "We click 'Trigger Live Assessment'. In the background, our LangGraph-orchestrated agent pipeline inventories all 50 datasets, scores them deterministically across five dimensions, and saves audit trails in SQLite." |
| **1:00 - 1:25** | **Lineage Trace Cascade (WOW MOMENT):** Navigate to the Lineage Trace page. Show the propagation graph animating with staggered reveals as downstream nodes turn orange/red. | "Here is the signature PRAXIS feature: Trust Propagation. When an upstream table like `orders` fails its schema tests, a cascading penalty spreads down the lineage tree, warning downstream charts and dashboards." |
| **1:25 - 1:45** | **Asset Deep Dive:** Click on a low-grade dataset. Show the 5-dimension radar-like scores, descriptions of failures (e.g., missing owner), and the **Remediation Preview** card. | "If we drill down into `order_details`, we see its compliance score is 43. PRAXIS identifies the exact gaps—like missing owners or assertions—and automatically generates remediation artifacts." |
| **1:45 - 2:05** | **GitHub Pull Request:** Click on the generated Pull Request link in the dashboard. Show the files tab in GitHub containing the generated `schema_orders.yml` and contracts. | "Our PR Agent writes these dbt tests and data contracts into a new branch and automatically creates a Pull Request on GitHub to fix the low-trust tables at the source." |
| **2:05 - 2:25** | **ML Gate Validation:** Paste 5 URNs into the ML Gate page. Click **Evaluate**. Show the result: **BLOCK_TRAINING** due to upstream propagation risks. | "We also provide an ML Gate. Before training a model, engineers paste their target URNs. The gate traces lineage, calculates risks, and issues a blocking verdict if upstream sources are dirty." |
| **2:25 - 2:45** | **Write-Back in DataHub:** Switch back to the DataHub UI. Reload the `orders` dataset. Show the new custom properties (`praxis_trust_score`, etc.) and the Daily Digest announcement on the home page. | "Finally, PRAXIS writes back its findings to DataHub. We see custom trust properties, tags, and a complete Daily Digest post published directly onto the DataHub homepage announcement board." |
| **2:45 - 3:00** | **Conclusion:** Slide showing the repository URL and live mock deployment link. | "PRAXIS: Audit your catalog, propagate risk, ship fixes, and gate models. Your data catalog gets smarter, cleaner, and safer every single day. Thank you." |
